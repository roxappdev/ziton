Зачем бизнесу платёжный шлюз

Интернет-эквайринг — это технология приёма оплаты на сайте или в приложении. Платёжный шлюз выступает посредником между покупателем, продавцом и банком: он безопасно передаёт данные карты, обрабатывает транзакцию и возвращает результат. Без платёжного шлюза не обойтись ни одному интернет-магазину, сервису подписок или маркетплейсу.

При выборе шлюза предприниматели обращают внимание на пять ключевых параметров: комиссию за транзакцию, скорость выплаты средств на счёт, набор поддерживаемых платёжных методов (банковские карты, СБП, SberPay, Яндекс Pay), удобство интеграции (качество API, наличие готовых модулей для CMS) и сроки холдирования (резервирования) средств. Не менее важна и качество документации — от неё напрямую зависит скорость разработки.

Ниже мы подробно разберём десять популярных решений на российском рынке, а в конце сведём их характеристики в сравнительную таблицу.

ЮKassa

Сайт: yookassa.ru

ЮKassa — платёжный сервис, входящий в экосистему Яндекса. Один из самых популярных шлюзов в России, особенно среди магазинов, интегрированных с Яндекс.Маркетом или использующих другие сервисы Яндекса.

Комиссия: от 2,8% за оплату банковской картой (Visa, Mastercard, Мир). Для юрлиц без расчётного счёта в банке-партнёре комиссия может быть выше. SberPay и Яндекс Pay — в рамках той же ставки.

Выплаты: на следующий рабочий день (Т+1) при использовании расчётного счёта в банке-партнёре, иначе Т+2–Т+3.

Методы оплаты: банковские карты (включая Мир), СБП, SberPay, Яндекс Pay, банковские переводы (для физлиц), электронные кошельки (ЮMoney), Apple Pay, Google Pay.

Интеграция: отличная документация на русском языке, SDK для PHP, Python, Java, Node.js, готовые модули для 1С-Битрикс, WordPress/WooCommerce, OpenCart, PrestaShop и других CMS. Поддержка библиотеки YooMoney Checkout в виде виджета оплаты — можно подключить за пару часов.

Холд: нет холдирования по умолчанию для стандартных продавцов. Резерв возможен при работе с высокорисковыми категориями.

Плюсы:

  • Максимально широкий набор платёжных методов
  • Глубокая интеграция с экосистемой Яндекса
  • Отличная документация и техническая поддержка
  • Высокий уровень доверия покупателей

Минусы:

  • Комиссия выше среднего у некоторых конкурентов
  • Строгая модерация при подключении (особенно для новых ИП)
  • Задержки выплат при подозрении на фрод

Робокасса (Robokassa)

Сайт: robokassa.ru

Робокасса — один из старейших платёжных сервисов в России, работающий с 2003 года. Популярен среди малого и среднего бизнеса благодаря простой процедуре подключения и гибкой тарифной сетке.

Комиссия: от 2,5% за банковские карты. Тарифы дифференцируются по объёму оборота — чем больше оборот, тем ниже ставка. Дополнительные методы (СБП, электронные кошельки) могут иметь отдельные комиссии.

Выплаты: ежедневно или раз в несколько дней в зависимости от тарифного плана. Стандартный цикл — Т+1–Т+3.

Методы оплаты: банковские карты, СБП, электронные кошельки (ЮMoney, QIWI — хотя QIWI прекращён), банковский перевод, салоны Евросети/Связной (остаточно), мобильная коммерция.

Интеграция: REST API с понятной документацией. Готовые модули для более чем 30 CMS и платформ (1С-Битрикс, WordPress, Joomla, OpenCart, ModX и др.). Также есть виджет оплаты и поддержка CMS-плагинов.

Холд: стандартный холд до 7 дней для новых merchants, сокращается до 1–3 дней при наращивании оборота.

Плюсы:

  • Низкая пороговая комиссия (от 2,5%)
  • Простая и быстрая регистрация
  • Огромное количество готовых CMS-модулей
  • Гибкая настройка уведомлений (webhooks)

Минусы:

  • Интерфейс личного кабинета выглядит устаревшим
  • Документация местами неполная
  • Поддержка отвечает медленнее, чем у ЮKassa
  • Холд для новых продавцов может достигать 7 дней

CloudPayments

Сайт: cloudpayments.ru

CloudPayments — современный платёжный шлюз с упором на разработчиков и технически подкованных предпринимателей. Сервис позиционирует себя как решение для быстрого старта онлайн-платежей.

Комиссия: от 2,5% за банковские карты. Для SaaS-проектов и подписок есть отдельные условия. Отдельные тарифы для рекуррентных платежей.

Выплаты: ежедневные (Т+1) при наличии расчётного счёта в банке-партнёре.

Методы оплаты: банковские карты (включая Мир), СБП, SberPay, Яндекс Pay, Apple Pay, Google Pay, электронные кошельки.

Интеграция: одна из лучших документаций на рынке. Чёткие примеры кода, тестовая среда (sandbox), SDK для всех основных языков. API поддерживает токенизацию карт, подписки (рекуррентные платежи), чаевые, split-платежи. Готовые плагины для популярных CMS.

Холд: минимальный — 1–2 дня для стандартных merchants. Для проектов с подписками возможна кастомная схема.

Плюсы:

  • Превосходная документация и API
  • Отличная поддержка рекуррентных платежей и подписок
  • Поддержка split-оплат и чаевых
  • Быстрое подключение (часто за 1–2 дня)

Минусы:

  • Меньше платёжных методов, чем у ЮKassa
  • Комиссия за некоторые методы выше
  • Нет собственной экосистемы бонусов для покупателей

Tinkoff Payments (Т-Платежа)

Сайт: tinkoff.ru/business/payments

Т-Платежа от Т-Банка (бывший Тинькофф) — платёжное решение, глубоко интегрированное в банковскую инфраструктуру. Особенно привлекательно для клиентов Т-Банка благодаря сниженным ставкам и моментальным выплатам.

Комиссия: от 1,5% до 2,8% за банковские карты в зависимости от тарифного плана банка и объёма оборота. Клиенты Т-Банка получают наиболее выгодные условия.

Выплаты: моментальные для клиентов Т-Банка (поступают на счёт сразу после транзакции). Для других банков — стандартные Т+1–Т+2.

Методы оплаты: банковские карты, СБП, T-Pay (платёжная система Т-Банка), Apple Pay, Google Pay, SberPay, Яндекс Pay.

Интеграция: качественная документация, SDK для популярных языков, готовые модули для основных CMS. API поддерживает токенизацию, recurrent-платежи, чекаут-виджет.

Холд: минимальный для клиентов Т-Банка (до 1 дня). Для остальных — стандартный 2–3 дня.

Плюсы:

  • Моментальные выплаты при расчётном счёте в Т-Банке
  • Одни из самых низких комиссий на рынке
  • Единая экосистема с банком и бухгалтерией
  • Надёжная техническая инфраструктура

Минусы:

  • Наилучшие условия доступны только клиентам Т-Банка
  • Менее гибкие настройки, чем у CloudPayments
  • Исторически проблемы с прохождением платежей картами других банков

СберКорус

Сайт: sberkorus.ru

СберКорус — платёжный сервис от экосистемы Сбера. Оптимальный выбор для компаний, уже использующих услуги Сбербанка для расчётного счёта.

Комиссия: от 2,2% за банковские карты. Для клиентов Сбербанка с высоким оборотом возможны индивидуальные тарифы.

Выплаты: Т+1 для клиентов Сбербанка, Т+2–Т+3 для остальных.

Методы оплаты: банковские карты, СБП, SberPay, SberPay+ (оплата бонусами «Спасибо»), Apple Pay, Google Pay.

Интеграция: документация на русском языке, API с поддержкой токенизации, рекуррентных платежей. Готовые модули для 1С-Битрикс, WordPress, OpenCart и других платформ.

Холд: 2–5 дней в зависимости от категории продавца и оборота.

Плюсы:

  • Глубокая интеграция с SberPay и бонусной системой «Спасибо»
  • Надёжная инфраструктура Сбербанка
  • Широкая сеть поддерживаемых платёжных методов

Минусы:

  • Документация уступает конкурентам
  • Подключение может занимать больше времени
  • Менее гибкие настройки по сравнению с CloudPayments и ЮKassa

PayMaster

Сайт: paymaster.ru

PayMaster — платёжное решение от группы компаний «Лига Цифровой Экономики» (входит в АО «НСПК»). Специализируется на приёме широкого спектра платежей, включая оплату ЖКХ, госуслуг и коммерческих сервисов.

Комиссия: от 2,3% за банковские карты. Тарифы зависят от объёма транзакций и категории бизнеса.

Выплаты: Т+1–Т+3 в стандартном режиме.

Методы оплаты: банковские карты, СБП, электронные кошельки, банковские переводы, оплата через терминалы и салоны связи.

Интеграция: API с документацией среднего качества, готовые плагины для популярных CMS. Поддержка виджета оплаты.

Холд: стандартный 3–7 дней для новых merchants.

Плюсы:

  • Широкий набор платёжных методов, включая нетипичные
  • Поддержка платежей за ЖКХ и госуслуги
  • Гибкие тарифы для крупных партнёров

Минусы:

  • Документация нуждается в улучшении
  • Меньше внимания к B2C-ecommerce
  • Поддержка медленная в пиковые периоды

Unitpay

Сайт: unitpay.money

Unitpay — платёжный сервис с фокусом на игры, цифровой контент и микроплатежи. Популярен среди инди-разработчиков и проектов с небольшим чеком.

Комиссия: от 2% за банковские карты — одна из самых низких на рынке. Дополнительная комиссия за вывод средств (от 1%).

Выплаты: по запросу, минимальная сумма вывода — 100 ₽. Стандартный срок обработки — 1–3 рабочих дня.

Методы оплаты: банковские карты, СБП, электронные кошельки (ЮMoney), мобильные операторы, криптовалюта (через партнёров).

Интеграция: простое API с базовой документацией. Готовые модули для популярных движков и CMS. Есть виджет оплаты и поддержка donation-кнопок.

Холд: 3–7 дней.

Плюсы:

  • Очень низкая комиссия (от 2%)
  • Поддержка криптоплатежей
  • Удобно для донатов и микроплатежей
  • Простая регистрация и быстрый старт

Минусы:

  • Ограниченный набор платёжных методов
  • Слабая техническая поддержка
  • Документация скудная
  • Репутация менее надёжного сервиса среди крупного бизнеса

ENOT

Сайт: enot.io

ENOT — платёжный шлюз, ориентированный на high-risk-проекты: онлайн-казино, беттинг, криптообменники, adult-контент. Работает как агрегатор, подключающий к нескольким банкам-эквайерам.

Комиссия: от 3,5% до 6% и выше — ставка зависит от risk-категории проекта. Для стандартного e-commerce — от 2,8%.

Выплаты: Т+3–Т+7 в зависимости от risk-уровня и банка-эквайера.

Методы оплаты: банковские карты, СБП, электронные кошельки, P2P-переводы, криптовалюта.

Интеграция: API с документацией среднего качества, поддержка токенизации, webhook-уведомления. Есть личный кабинет с аналитикой.

Холд: от 7 до 30 дней для high-risk проектов. Стандартные — 3–7 дней.

Плюсы:

  • Готовность работать с high-risk-проектами
  • Поддержка P2P и криптовалюты
  • Подключение к нескольким банкам-эквайерам

Минусы:

  • Высокие комиссии
  • Длительный холд
  • Репутация специфического сервиса
  • Ограниченный функционал для классического e-commerce

LAVA Pay

Сайт: lavapay.ru

LAVA Pay — сравнительно новый платёжный шлюз, ориентированный на интернет-магазины и сервисы подписок. Позиционируется как современное решение с простым подключением.

Комиссия: от 2,5% за банковские карты. Для подписок и рекуррентных платежей — индивидуальные условия.

Выплаты: Т+1–Т+2.

Методы оплаты: банковские карты, СБП, SberPay, Яндекс Pay, электронные кошельки.

Интеграция: современное REST API с документацией хорошего качества. SDK для основных языков программирования, готовые плагины для популярных CMS.

Холд: 2–5 дней.

Плюсы:

  • Современный интерфейс личного кабинета
  • Хорошая документация
  • Гибкие условия для SaaS-проектов
  • Поддержка split-оплат

Минусы:

  • Относительно молодой сервис
  • Меньше известных интеграций
  • Комиссия не самая низкая

Stripe (зарубежная альтернатива)

Сайт: stripe.com

Stripe — мировой лидер среди платёжных шлюзов, однако с 2024 года его использование для российских компаний сильно ограничено из-за санкций. Упомянаем его для полноты картины и для проектов, ориентированных на международный рынок.

Комиссия: 2,9% + $0,30 за транзакцию (международные карты). Дополнительные сборы за валютную конвертацию.

Выплаты: Т+2–Т+7 в зависимости от страны банка.

Методы оплаты: карты Visa, Mastercard, Amex, Apple Pay, Google Pay, Alipay, WeChat Pay, SEPA, локальные методы более чем в 45 странах.

Плюсы:

  • Лучшее в мире API и документация
  • Огромное количество платёжных методов
  • Поддержка подписок, split-оплат, marketplace-платежей
  • Глобальный охват

Минусы:

  • Недоступен для резидентов РФ
  • Санкционные ограничения
  • Комиссия в долларах с дополнительными сборами

Как выбрать платёжный шлюз

Выбор зависит от конкретных задач бизнеса. Для интернет-магазинов с широким ассортиментом лучше всего подойдут ЮKassa или Т-Платежа — они предлагают максимальный набор платёжных методов и быстрый старт. Для SaaS-проектов и сервисов подписок оптимальны CloudPayments и LAVA Pay благодаря продвинутой поддержке рекуррентных платежей. Малому бизнесу и индивидуальным предпринимателям стоит присмотреться к Робокассе или Unitpay из-за низкого порога входа. Если расчётный счёт уже открыт в Т-Банке, Т-Платежа станет самым выгодным решением за счёт моментальных выплат и пониженных комиссий.

Рекомендуем подключить два платёжных шлюза в качестве резервных — это повысит отказоустойчивость и обеспечит непрерывный приём оплат даже при технических сбоях одного из провайдеров.
